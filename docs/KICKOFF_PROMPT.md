# Codex / Claude Codeへの最初の指示（この本文を貼り付ける）

あなたはシニアフルスタックエンジニア、UI/UXデザイナー、QAリードを兼務し、StudyFlightという独自の集中学習Webアプリを実装してください。

このフォルダの `AGENTS.md`、`PRODUCT_SPEC.md`、`STYLE_GUIDE.md`、`TASKS.md`、`CONTINUATION.md` をすべて読み、既存のファイル・変更を尊重してください。Claude Codeでは `CLAUDE.md` も参照してください。

**ゴール:** iPhoneでネイティブアプリのように使用できるPWA。科目・学習タスクを設定し、世界の空港間を移動する仮想フライトとして集中タイマーを実行し、着陸とともに学習履歴・統計・SkyPoints・訪問空港を保存できること。静的モックで完成扱いにしないこと。

**技術:** Next.js (App Router)、TypeScript strict、Tailwind CSS、Dexie/IndexedDB、Zustand（UI状態のみ）、Zod、MapLibre GL JS、Vitest、Playwright。ライブラリバージョンはインストール時点の公式互換性を確認して選定する。

**最優先事項:** タイマーをタイムスタンプ＋focusSegmentsから復元し、一時停止・バックグラウンド復帰・リロード・日付跨ぎ・二重着陸に対して正しく動作させる。地図表示の問題でセッションを失わない。端末内データの保護・バックアップも重視する。

**デザイン:** ダークネイビーを基調にした上質な夜間飛行の世界観。オリジナルの画面・アイコンを作る。搭乗券、3D地球儀、飛行中のHUD、着陸、FlightLog、分析、Passportを統一したモバイルファーストUIで構築する。既存製品の名称・画像・固有デザインをコピーしない。

**進め方:**
1. 既存Git状態とファイル内容を確認し、実装計画を短く示す。
2. `TASKS.md` の Phase 0 から取り掛かり、動く縦方向スライスを優先してPhase 1へ進む。
3. 必要なコード、テスト、開発サーバで動く画面を作り、実行できる範囲で lint、typecheck、unit tests、build、E2Eを検証する。
4. 各区切りに `TASKS.md` の進捗を更新し、`CONTINUATION.md` に変更・テスト・ブロッカー・再開手順を記録する。
5. 外部サービスの有料契約、APIキー登録、公開デプロイ、破壊的操作など事前承認が必要なことは勝手に行わない。許可なく実現できる機能から先に進める。
6. 細かい仕様の曖昧さは妥当な判断をして実装し、判断理由を記録する。コーディングとテストを実際に進める。

今すぐリポジトリを調べて Phase 0 を実装し、できる範囲でPhase 1まで進めてください。完了/未完了/テスト結果/次にすることを明確に報告してください。
